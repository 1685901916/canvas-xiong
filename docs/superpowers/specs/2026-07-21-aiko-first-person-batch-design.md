# AIKO 第一人称首帧批量画布设计

## 目标

创建一个独立、可检查、可再次运行的 Infinite Canvas 画布，用同一张 AIKO 三视图身份参考生成六个地点的第一人称视频首帧，每个地点三张，共十八张。

## 画布结构

每个地点是一项独立生成需求：

```text
[ Group：AIKO参考图 + 地点提示词 ] -> [ API生成 ] -> [ 固定尺寸Output ]
```

共六组、六个可见生成节点、六个输出节点。每个生成节点的目标总数为三张，不按 provider 数量倍增。

## 生成设置

- 画布：`AIKO第一人称首帧批量测试_20260721`
- 角色参考：`D:\本地资源库\AIKO\三视图\整洁顺滑的银白猫耳发_517b317a.png`
- Provider：`65535` (`custom-api-2`)
- Model：`gpt-image-2`
- Ratio：`9:16`
- Resolution：`1k`
- Quality：`auto`
- Count：每地点三张

## 六个地点

1. 公寓玄关：AIKO刚回家，观众在室内等待，阳光治愈。
2. 厨房柜台：AIKO递来热饮，日常亲切。
3. 咖啡店对座：桌面前景，安静约会。
4. 雨天公交站：共处伞下，温柔暧昧。
5. 清晨床边：观众低机位，AIKO温柔叫醒。
6. 河边长椅：并肩位置，克制沉重。

## 统一角色与画质要求

- 参考图仅锁定 AIKO 的成年角色身份、脸型、红粉色眼睛、银白长发、猫耳与桃粉耳内，不继承三视图排版或白底。
- 统一穿白色上衣、浅蓝色宽松针织外套、浅蓝蝴蝶结和灰色格纹百褶裙。
- 头发整洁柔顺、成束清晰，有真实有效纹理；禁止杂毛、油光、塑料高光、密集假发丝和脏污噪点。
- 第一人称位置明确，双眼自然聚焦镜头；不得出现手机、相机、自拍杆、额外手臂或异常手指。
- 面部明亮清晰，环境可辨认但不杂乱，不偏绿、不压黑、不真人化、不3D化。
- 首帧不是动作高潮，必须给后续10秒视频留出靠近、转身、递物或表情变化空间。

## 验收

- 保存画布 JSON 中存在六组、六个 prompt、六个 generator、六个 output。
- 每组只有一个可见上游生成节点，输出节点固定尺寸并可滚动。
- 每个生成节点 count 为三，成功图片进入对应输出节点。
- 目标共十八张；失败、占位或不可用结果不计入合格数。
- 保留全部结果供用户比较，不自动隐藏差图。
