# 自由合成画板设计

## 目标

在普通无限画布中选中至少一张图片后，打开一个接近 Photoshop 图层操作的自由合成窗口。用户可以直接拖入更多图片，并独立调整每个分件的位置、比例、旋转、透明度和层级，最后把结果作为一张新的 PNG 图片节点放回原画布。

## 入口与流程

1. 用户在普通画布中选中一张或多张图片节点。
2. 顶部工具栏出现“自由合成”按钮；至少一张有效图片即可打开。
3. 打开全屏模态编辑器，默认画板尺寸取第一张（最底层）图片的原始尺寸；也可切换常用尺寸或输入宽高。
4. 所选图片按画布中的节点顺序成为图层；第一张铺满画板，其余图片按原始比例居中放置。
5. 用户在画板或图层面板选中图层，进行拖动、八方向缩放、旋转、隐藏、锁定、重命名和层级调整。
6. 点击“生成到画布”后，以 PNG 上传现有媒体接口，并在原选区右侧生成新的图片节点；源节点保持不变。

## 直接拖入图片

- 用户可从 Windows 资源管理器把 PNG、JPEG、WEBP 或 GIF 直接拖到合成编辑器。
- 画板和画板外的深色编辑区都是有效放置目标；拖入时显示明确的高亮边框和“松开以放置图片”提示。
- 松开鼠标后，每张图片立即成为独立图层，图层中心与鼠标落点对齐。
- 小图保持原始像素尺寸；任一边超出画板 80% 时，等比缩小到画板 80% 范围内，不放大低分辨率图片。
- 一次拖入多张时，以落点为中心每张向右下偏移 24px，最后一张位于最上层并自动选中。
- 导入完成后立即显示变换框，无需再点击“添加图层”或确认对话框。
- 不支持的文件不会创建空图层；多文件拖入时，有效图片继续导入，并汇总提示被跳过的文件。

## 交互模型

- 画板：固定像素尺寸，透明棋盘格背景，可选择透明、白色或自定义纯色背景。
- 图层：保存 `id/name/url/x/y/width/height/rotation/opacity/visible/locked/naturalWidth/naturalHeight`。
- 选框：四角默认保持比例缩放，四边自由缩放，上方旋转手柄；Shift 临时解除四角的比例锁定，Alt 从中心缩放。
- 移动：鼠标拖动；方向键移动 1px，Shift+方向键移动 10px。
- 对齐：吸附画板边缘、水平/垂直中心线以及其他图层边缘，显示临时参考线。
- 图层面板：拖拽排序、上移/下移、置顶/置底、显示、锁定、删除和复制。
- 历史：合成窗口内独立撤销/重做，最多保留 50 个状态。
- 导出：按画板真实像素离屏渲染；旋转、透明度和图层顺序与预览一致。

## 架构

- `free-compositor-core.js`：纯数据模型、几何变换、导入尺寸计算、历史和导出绘制顺序；使用 UMD 形式，浏览器和 Node 测试均可加载。
- `free-compositor.js`：DOM 编辑器、文件拖入、指针交互、键盘快捷键、图片预加载和导出。
- `free-compositor.css`：模态窗口、画板、图层面板、属性面板、选框及参考线样式。
- `canvas.js`：只提供选中图片读取、上传结果和创建结果节点的适配器。
- `canvas.html`：加载样式和脚本，并挂载编辑器根节点。

## 数据与兼容性

第一版的编辑状态只存在于模态窗口内；关闭时丢弃，输出结果作为普通图片节点进入现有保存机制。这样不改变现有画布 JSON 结构，也不会影响旧画布。后续如需要可把合成工程作为单独节点类型持久化。

## 错误处理

- 没有有效图片、包含视频/音频、图片加载失败或跨域画布污染时，阻止导出并显示具体图层名称。
- 超大画板导出前检查像素数量，超过安全阈值时提示缩小尺寸。
- 导出或上传失败时保留编辑现场，允许重试。

## 验收标准

- 一张或多张图片可从普通画布进入自由合成窗口。
- 本地图片可从系统文件管理器直接拖入编辑区，在落点创建独立图层并自动显示变换框。
- 超大图片等比适配画板 80% 范围，小图不被放大，多图拖入保持文件顺序和 24px 错位。
- 每层可拖动、缩放、旋转、调透明度、隐藏、锁定和排序。
- 画板尺寸可编辑，预览与导出的 PNG 位置、旋转、比例和层级一致。
- 导出后自动生成新的图片节点，原节点不变。
- 核心几何、层级、历史和 HTML 接入均有自动化测试。
