# AIKO2D Midnight Swim Layout Redesign

## Objective

Redesign the four English AIKO2D Midnight Swim campaign images so they read as screens from a polished mobile companion game rather than character posters or magazine covers.

## Shared Visual System

- Format: vertical 9:16, high quality, 2K request size.
- Setting: midnight rooftop pool with deep navy, violet neon, moonlight, water reflections, and restrained atmospheric depth.
- Character: the same clearly adult 25-year-old silver-haired catwoman from the identity reference, with white cat ears and rose-red eyes.
- Character placement: integrated naturally into the scene, generally within the middle 60% of the composition and occupying no more than about 40% of the total poster area.
- Typography: modern game-interface sans serif only; no oversized editorial serif headlines.
- UI language: one coherent dark translucent bottom sheet, one primary violet action button, consistent corner radius, spacing, borders, and alignment across all four images.
- Restraint: no three-column feature lists, repeated logos, decorative icon clouds, fake store badges, QR codes, reviews, or stacked glass panels.

## Master Layout

1. Top 10%: small AIKO2D logo and one short section label.
2. Middle 60%: uninterrupted character-and-environment key art with clean focal depth.
3. Bottom 30%: one dark translucent action sheet containing a title, one short supporting sentence, one optional compact status element, and one primary button.

The action sheet must look operable and must not cover the character's face or important silhouette. Copy should remain short enough for accurate English rendering.

## Four Screens

### 1. Event Entry

- Section label: `LIMITED EVENT`
- Title: `MIDNIGHT SWIM`
- Supporting copy: `A private story beneath the moonlight.`
- Compact status: `ENDS IN 06D 18H`
- Primary button: `ENTER EVENT`

### 2. Story Choice

- Section label: `INTERACTIVE STORY`
- Title: `CHOOSE YOUR REPLY`
- One short AIKO dialogue line above two restrained choice rows.
- Choices: `STAY WITH HER` and `MAKE HER SMILE`
- No additional CTA; the two choices are the interaction.

### 3. Voice Call

- Section label: `VOICE COMPANION`
- Title: `AIKO IS CALLING`
- One compact waveform and call timer in the bottom sheet.
- Primary button: `ANSWER`

### 4. Bond Reward

- Section label: `BOND REWARD`
- Title: `LEVEL 07 REACHED`
- One compact progress bar and one small outfit reward thumbnail.
- Primary button: `CLAIM REWARD`

## Acceptance Criteria

- The four images visibly share one UI kit and grid.
- Each image reads as a playable mobile-game screen within one glance.
- Character art and interface do not compete for attention.
- No giant serif headline or interface panel dominates more than the intended bottom 30%.
- Each screen contains one clear task and no unrelated feature advertising.
- English labels and calls to action are readable and correctly spelled.
- Existing accepted outputs remain visible in the canvas for comparison; new versions are added as a separate redesign set.
- Every redesign lane is inspectable as `Group -> Generator -> Output` with references and prompt inside the Group.

## Generation and Review

Generate one candidate per screen first. Review layout consistency, game-screen credibility, identity fidelity, text accuracy, and clutter. Refill only failed or rejected screens. Preserve task metadata and rejection reasons in the connected output nodes.
